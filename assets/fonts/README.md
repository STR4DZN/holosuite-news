# HoloNews fonts

Local WOFF2 subsets derived from Google Fonts, under SIL Open Font License 1.1. Copyright and license metadata retained; derivative families renamed HN Editorial Serif, HN Civic Sans, HN Civic Mono, HN Geometric and HN Condensed. Latin / Latin Extended and common punctuation; other scripts use the CSS fallback. No external runtime request.

Sources: https://github.com/google/fonts/tree/main/ofl/sourceserif4 (Adobe); https://github.com/google/fonts/tree/main/ofl/ibmplexsans and https://github.com/google/fonts/tree/main/ofl/ibmplexmono (IBM); https://github.com/google/fonts/tree/main/ofl/spacegrotesk (Florian Karsten); https://github.com/google/fonts/tree/main/ofl/barlowcondensed (Jeremy Tribby).

Variable axes retained where present. Each family license accompanies the files.
